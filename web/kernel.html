Limites de cette console

À connaître

Cette page exécute des contrôles front-end et des requêtes de lecture vers l’API configurée. Elle ne prétend pas exécuter le moteur Python depuis le navigateur : aucun endpoint public de test du kernel n’est défini à ce stade. Le kernel Python réel est validé par la suite CI GitHub Actions, qui exécute les tests Python et l’intégration Worker ↔ moteur sans réseau. Cette UI ne soumet aucun ordre ni configuration.
