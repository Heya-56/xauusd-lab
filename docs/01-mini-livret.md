# Mini-livret — XAUUSD Lab depuis un téléphone

## Expérience standard
- XAUUSD
- 14:00 Pacific/Tahiti
- lundi / mercredi / vendredi
- M5
- maximum 1 trade par journée d'expérience
- backtest d'abord

## Candidats open source
Pour chaque repo candidat : URL, licence, stars/forks, activité récente, timeframe, dépendances, règles, métriques annoncées, métriques reproduites, résultats out-of-sample et sensibilité aux coûts/slippage.

Un README n'est jamais traité comme une preuve de performance.
